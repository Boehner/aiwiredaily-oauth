Privacy Policy

Last updated: 2026-08-22

AIWireDaily is a single-operator automation that produces and uploads a daily AI-news video brief to the AIWireDaily YouTube channel. This policy explains how the application that powers it uses Google APIs.

Who uses this application

This application is used exclusively by the developer and owner of the AIWireDaily YouTube channel to authorize automated video uploads. It is not distributed to, or used by, any other end users.

What data is accessed

The application requests access to the YouTube Data API (upload scope) solely to upload video files, thumbnails, titles, descriptions, and playlist assignments to the AIWireDaily channel. It does not read, access, or process any data belonging to other Google or YouTube accounts.

What data is collected or stored

No personal data from third parties is collected. The application stores only an OAuth refresh token, used solely to authenticate the channel-owner's own automated uploads, on infrastructure controlled by the developer. Source material for videos consists of publicly available news articles, used for summarization purposes only.

Data sharing

No data is sold, shared, or disclosed to third parties. The only third-party interaction is the YouTube Data API itself, used as described above.
